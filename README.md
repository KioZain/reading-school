# Школа чтения — функциональный прототип

Запуск: `npm install`, затем `npm run dev`. Открыть http://127.0.0.1:5173.

Проверки: `npm run build`, `npm test`, `npm run test:e2e`. Браузерные проверки используют установленный Google Chrome.

Источник требований: /Users/maxim_kio/Projects/reading-app/documentation/prototype/specification.md и tasks.md. Реализация выполняется здесь, согласно прямому указанию пользователя. Pofo используется во всём интерфейсе; Ahner — только для учебных слов и подписей слогов в сценах.

Маршрут: три онбординга → карта → вводная → первые слова → кузнечик → кузовок → листья → тучки → гаражи → звезда → необязательный профиль → карта → тренировка → итог. На карте также доступны профиль, настройки и вводная второго урока после первого завершения. В упражнениях читайте по дуге каждого слога слева направо. В кузовке и гаражах затем перетащите предмет. В листьях и тучках выберите объект после чтения.

Состояние хранится только в памяти. Обновление страницы сбрасывает сеанс. Публикация не выполнялась. Финальные иллюстрации и художественные анимации относятся к отдельному этапу.

Ограничения проверки: физический мобильный экран и реальное касание не проверены; длительность показа с человеком не измерялась. Справочные страницы настроек содержат краткие нейтральные тексты, без рабочих аккаунтов и оплаты.
