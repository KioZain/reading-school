# Школа чтения — функциональный прототип

Запуск: `npm install`, затем `npm run dev`. Открыть http://127.0.0.1:5173.

Проверки: `npm run build`, `npm test`, `npm run test:e2e`. Браузерные проверки используют установленный Google Chrome.

Источник требований: /Users/maxim_kio/Projects/reading-app/documentation/prototype/specification.md и tasks.md. Реализация выполняется здесь, согласно прямому указанию пользователя. Pofo используется во всём интерфейсе; Ahner — только для учебных слов и подписей слогов в сценах.

Маршрут: три онбординга → карта → вводная → первые слова → кузнечик → кузовок → листья → тучки → гаражи → звезда → необязательный профиль → карта → тренировка → итог. На карте также доступны профиль, настройки и вводная второго урока после первого завершения. В упражнениях читайте по дуге каждого слога слева направо. В кузовке и гаражах затем перетащите предмет. В листьях и тучках выберите объект после чтения.

Состояние хранится только в памяти. Обновление страницы сбрасывает сеанс. Публикация не выполнялась. Финальные иллюстрации и художественные анимации относятся к отдельному этапу.

Ограничения проверки: физический мобильный экран и реальное касание не проверены; длительность показа с человеком не измерялась. Аккаунт и оплата работают как демонстрационные сценарии в памяти страницы; настоящего сервера, писем и списаний нет.

## Новое управление уроком

В задании доступны отмена шага, «Проиграть заново» (только демонстрация подсветки) и вопросительный знак со справкой для взрослого. Профиля и настроек в учебных экранах нет. На вводной есть озвучка; звук останавливается при выходе.

После завершения урока нажмите «Домой» в панели: через 450ms на карте один раз появится предложение профиля. Нажатие на пройденный маркер открывает выбор тренировки и полного повтора. Прерванная тренировка продолжается, завершённая запускается заново.

Документы: [изменения логики](design-plans/2026-11-03-learning-controls-functional-changelog.md) и [отдельная задача на визуал](design-plans/2026-11-03-learning-controls-visual-handoff.md). Озвучка — синтезированный русский голос Milena; файл и текст находятся в `public/audio/`.


## Профиль и аккаунт взрослого

Профиль показывает разные прочитанные слова, завершённые уроки, тренировки и четыре награды с условиями получения. В настройках ребёнка можно изменить имя, персонажа и фон с предварительным просмотром и отменой изменений.

Через профиль или настройки доступны регистрация взрослого, вход, восстановление пароля, выход и условная покупка. Можно проверить успех, отказ, повтор, отмену и восстановление доступа. Тестовая цена — 990 ₽, списаний нет. Данные сеанса исчезают при обновлении страницы. Вход не обязателен для первого урока и тренировки.
