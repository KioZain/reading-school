# GitHub Pages

Репозиторий: https://github.com/KioZain/reading-school
Ожидаемый адрес без собственного домена: https://kiozain.github.io/reading-school/

## Разовое включение

1. В настройках репозитория откройте **Settings → Pages → Build and deployment**.
2. В поле **Source** выберите **GitHub Actions**.
3. Отправьте настройку `.github/workflows/pages.yml` и законченные изменения приложения в `main`.
4. В **Actions → Deploy to GitHub Pages** дождитесь зелёного результата. Адрес сайта также появится в окружении `github-pages`.

Если настройка уже в `main`, первый запуск можно сделать через **Run workflow → main**. После этого новые push в `main` публикуются автоматически. Локальные несохранённые в Git изменения не попадают на сайт.

## Что делает процесс

- Устанавливает Node.js 24 и зависимости из `package-lock.json` через `npm ci`.
- Запускает модульные тесты; при ошибке публикация не начинается.
- Получает путь сайта из `actions/configure-pages`.
- Собирает приложение с `PAGES_BASE_PATH`, упаковывает только `dist` и публикует официальным `actions/deploy-pages`.
- Использует встроенный `GITHUB_TOKEN` с отдельными правами сборки и публикации. Отдельный токен или пароль в секретах не нужен.
- Выполняет деплои последовательно. Ручной запуск из другой ветки собирает артефакт, но не публикует его.

Основная конфигурация — `.github/workflows/pages.yml`, адрес сборки — `vite.config.ts`. Версии официальных actions закреплены по SHA; теги проверены в официальных репозиториях GitHub.

## Проверка подпапки локально

```sh
PAGES_BASE_PATH=/reading-school/ npm run build
PAGES_BASE_PATH=/reading-school/ npx vite preview --host 127.0.0.1 --port 4173
```

Открыть http://127.0.0.1:4173/reading-school/ и проверить загрузку шрифтов и озвучку на вводной. Обычный `npm run dev` продолжает работать от корня.

Пути к файлам из `public` в приложении должны использовать `import.meta.env.BASE_URL`, например:

```ts
const audioUrl = `${import.meta.env.BASE_URL}audio/lesson-one-intro.m4a`;
```

Не использовать `/audio/...`: это корень домена, тогда как сайт проекта находится в `/reading-school/`. Импортируемые шрифты и другие ресурсы Vite перепишет самостоятельно.

## Повторная публикация и откат

Для повтора используйте **Re-run jobs** у нужного запуска. Для отката отправьте в `main` отмену проблемного коммита: обычный workflow соберёт и опубликует предыдущую рабочую версию. Публикация не меняет историю или файлы исходного кода.

## Проверка настройки

Локально прошли 16 модульных проверок и production-сборка с базой `/reading-school/`. В браузере проверены оба шрифта, реальное воспроизведение озвучки и вход в задание; ошибок загрузки и JavaScript нет. YAML workflow разобран без ошибок.

Удалённый запуск Actions и состояние Pages не проверены: в доступной сессии нет авторизации GitHub. Файлы не закоммичены и не отправлены на сервер, чтобы настройка могла войти в Git вместе с законченным параллельным рефактором. Для активации выполнить разовые шаги выше.
