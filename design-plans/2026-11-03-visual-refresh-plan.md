# План визуальной доработки: «мягкий детский» UI

Дата: 3 ноября 2026. Статус: этапы 1–7 выполнены (см. «Итог реализации» в конце).
Цель прототипа: приблизиться к референсам на уровне иконок, кнопок и системных компонентов — крупно, мягко, по-детски наивно, с псевдообъёмными кнопками. Учебная логика, маршруты и тесты поведения не меняются.

## 1. Что сейчас и почему «пресно»

| Сейчас | Эффект |
| --- | --- |
| Приглушённая шалфейная палитра (`#4e7359`, `#edf1e1`, `#dce3cf`) — почти один тон на весь экран | Нет акцентов, всё «серо-зелёное», мало радости |
| Иконки — тонкий контур `stroke 1.65` на сетке 24×24, почти без заливок и цвета | Выглядят как системные иконки взрослого приложения |
| Кнопки плоские: `.primary` с тенью 4px почти прозрачной, `.secondary` — бледная плашка с бордером 1px | Нет ощущения «нажимаемой игрушки» |
| Мелкая типографика: eyebrow 11px капсом, подписи 12–14px | Взрослая, «интерфейсная» иерархия |
| Сцены упражнений — однотонные прямоугольники `--color-sage` | Нет пространства, нет мира |
| Персонажи (медведь, кузнечик, лиса) — схемы из 2–3 фигур без характера | Нет эмоциональной привязки |

## 2. Визуальный язык из референсов

Общие черты всех пяти картинок, которые переносим (без копирования конкретных персонажей и стилистики чужих продуктов):

1. **Псевдообъём через «губу»**: у кнопки/плитки снизу более тёмная полоса того же цвета (4–8px), сверху лёгкий светлый блик. При нажатии элемент «проседает» в губу. Это главный приём из реф. 1 и 3 (буквенные плитки, инструменты, «Keep Drawing»).
2. **Заливка вместо контура**: иконки и объекты — плотные цветные формы с минимумом линий; детали (глаза, блики) — точками и короткими штрихами (реф. 3, 4, 5).
3. **Лица у предметов**: глаза-точки + румянец оживляют тучку, солнце, машинку, гараж (реф. 3, 5).
4. **Крупные скругления**: 24–32px у плиток, «пилюли» у CTA, круги у аватаров и навигации.
5. **Тёплый светлый фон + насыщенные акценты**: кремовая основа, 5–6 ярких «игрушечных» цветов, каждый в трёх ступенях (тинт / база / губа).
6. **Мир вокруг**: слоистые холмы, облака, точечный паттерн на фоне (реф. 1, 3, 5).
7. **Награда как событие**: лучи-бёрст, крупная звезда/медаль, конфетти-точки (реф. 1, 2).

## 3. Фиксированные ограничения (не нарушаем)

- Pofo — весь интерфейс; Ahner — только учебные слова и слоги.
- Учебные буквы не двигаются; координаты дорожек `pathFor` и `viewBox 140×125` у `ReadingSurface` не меняются (иначе сломается распознавание жеста).
- Минимум интерактивной зоны `--target-min: 56px` — только увеличиваем.
- Landscape 667×375 … 1200×800 и низкий 667×320 должны помещаться; portrait-заглушка сохраняется.
- Reduced motion и клавиатурный режим: без перемещений, только мгновенные смены цвета/тени.
- Существующие e2e и визуальные тесты остаются зелёными; тесты, завязанные на старую геометрию иконок (машина, лист), обновляются вместе с иконками, а не удаляются.

### Этап 2. Система кнопок с псевдообъёмом (`src/styles.css`)

Единый базовый класс + модификаторы вместо разрозненных `.primary`, `.secondary`, `.icon-button`, `.menu button`, `.lesson-marker`:

```
.btn               база: Pofo Bold 18px, высота 64 (56 в компактной), pill-радиус
.btn--grass        основное действие (зелёная)
.btn--sun / --orange / --sky / --lavender   цветовые варианты
.btn--paper        вторичная: белая с бежевой губой и тёмным текстом
.btn--icon         круглая 64×64 (56 компакт), иконка 32px
.btn--tile         крупная плитка-карточка (меню, урок на карте)
```

Устройство одной кнопки:
- фон — база цвета; `box-shadow: 0 var(--lip) 0 var(--lip-color), var(--shadow-soft)`;
- блик сверху: `inset 0 3px 0 rgb(255 255 255 / .35)` + тонкая внутренняя тень снизу `inset 0 -2px 0 rgb(0 0 0 / .08)`;
- нажатие: `translateY(var(--lip))` + губа схлопывается до `0` — кнопка «утапливается» (140ms, существующий `--motion-press`);
- hover (только точный указатель): осветление базы на ~6%;
- disabled: серо-кремовая заливка, губа сохраняется, но приглушена; без утапливания;
- focus-visible: толстое кольцо 4px цвета «солнце» с отступом.
- reduced motion / клавиатура: без `translateY`, только мгновенная смена губы и прозрачности.

Важно: у листьев и тучек вращение уже отделено через свойство `rotate`; новое нажатие использует `transform: translateY` — тест «лист сохраняет угол» продолжит проходить.

Компоненты, которые получают эту систему:
- кнопки центральных экранов (Далее / Пропустить / Домой / Пройти заново / Следующий урок);
- кнопки шапки (Домой, Отменить шаг, Профиль, Настройки) — круглые белые с губой, как в реф. 5;
- маркеры уроков на карте — крупные круги 84px (66 компакт) с цифрой Pofo Black;
- плитки меню настроек — 2 колонки, у каждой цветной кружок с иконкой слева;
- аватары — круглые жетоны;
- перетаскиваемые предметы и гаражи — плитки с губой (как буквенные плитки реф. 3).

### Этап 3. Новый набор иконок (`src/Icon.tsx`)

Два семейства с разными правилами:

**A. Системные глифы** (`home, undo, arrow, settings, profile, lock, check, star, info, trail`):
- плотные залитые формы, `stroke-width 2.6–3` для того, что остаётся линией;
- скруглённые концы и углы, упрощённая геометрия (домик — «пряничный», замок — круглый, шестерёнка — цветок с 6 лепестками);
- цвет — `currentColor`, чтобы работали на любых кнопках;
- сетка 24×24 сохраняется (проходит тест «помещается в viewBox»).

**B. Иллюстрации-персонажи и предметы** (`bear, bug→кузнечик, fox, sun, flower, leaf, cloud, cake, car, pencil, notebook, book`):
- многоцветная плоская заливка из палитры, без общего контура или с мягким контуром цвета губы;
- лица: глаза-точки, румянец ягодным цветом, улыбка-дуга — у солнца, тучки, кузнечика, медведя, лисы, машинки;
- собственный `viewBox 64×64` для детализации (компонент `Icon` научить брать viewBox из описания иконки);
- плотные формы, без тонких внутренних линий; блик — светлое пятно.

Сохранить смысловые части для тестов: у листа `data-part="blade"` и `data-part="vein"` (жилка без заливки), у машины колёса — отдельные `circle`, контур кузова не пересекает их центры. Тест «машина» и фикстура `tests/fixtures/icons.tsx` обновляются под новую геометрию.

Новые элементы набора:
- 2–3 дополнительных аватара-зверька (зайчик, цыплёнок, котик) вместо абстрактных `○ ☀ ✿` — без изменения модели данных: значения символов остаются ключами, меняется только `avatarIcon`. Нужно согласование (см. «Вопросы»).
- декоративные: `hill`, `cloud-puff`, `sparkle`, `confetti` — для фонов и наград.

### Этап 4. Поверхности и фон

- `body` и рамка устройства: тёплый фон + лёгкий точечный паттерн (`radial-gradient`, как в реф. 1); рамка устройства мягче и светлее.
- Карточки (`.card`): белые, радиус 32, губа `--paper-lip` 6px + мягкая тень.
- Сцены упражнений: вместо однотонного прямоугольника — «мир»: небо-градиент + 2 слоя холмов (SVG/CSS-волны) + 1–2 облачка; у каждой сцены свой оттенок (лесенка — луг, кузовок — опушка, листья — осень, тучки — небо, гаражи — улица). Геометрия и `overflow:hidden` сцены сохраняются.
- Панель чтения: белая карточка-подложка под словом, чтобы слоги читались на «листе».

### Этап 6. Движение (минимально, в рамках токенов)

- Нажатие — «утапливание» в губу вместо `scale(.96)`.
- Иконки-персонажи: существующий `SpringArt` (500ms, bounce .2) — без изменений.
- Награда: однократный «поп» звезды + статичное конфетти; пульс текущего урока на карте — opacity/scale кольца, не самого маркера.
- Reduced motion и клавиатура — как сейчас: никаких перемещений.

### Этап 7. Проверка

- `npm run build`, `npm test`, `npm run test:e2e` — все зелёные; тест 56px продолжает проверять все кнопки/поля/аватары.
- Обновлённая фикстура иконок → контактный лист «до/после» в `design-plans/evidence/`.
- Скриншоты всех ключевых экранов на 667×375, 844×390, 932×430, 667×320.
- Контраст: белый текст на `grass` и `orange` проверить на AA для крупного текста (≥3:1); при нехватке — затемнить базу или перевести текст на тёмные чернила.

## 6. Вопросы до старта

1. **Основной цвет действий**: оставить зелёный, но сделать его ярким «травяным» (`#4cc35a`), или перейти на тёплый жёлто-оранжевый как в реф. 1/2?
2. **Стиль иллюстраций**: плоская заливка без контура (реф. 3, 4) или мягкие «стикеры» с цветным контуром и бликами (реф. 1, 5)?
3. **Талисман**: добавить сквозного персонажа-проводника (появляется на онбординге, в итогах, в пустых зонах) или ограничиться оживлением существующих героев сцен?
4. **Аватары**: заменить абстрактные `○ ☀ ✿` на зверьков (оставив ключи в данных)?

## Итог реализации

Решения по вопросам (ответа не было, приняты значения по умолчанию): яркий зелёный для действий (`#38a948`, белый текст ≈3:1 для крупного жирного), плоские иллюстрации с лицами, без сквозного талисмана, аватары-зверьки (зайчик, цыплёнок, лягушонок, медвежонок, лисёнок; ключи `○ ☀ ✿ 🐻 🦊` в данных не менялись).

- `tokens.css`: палитра тинт/база/губа, радиусы, глубины губы, мягкая тень, `--target-comfort: 64px`.
- `styles.css`: общая система объёмных кнопок для `.primary`, `.secondary`, `.icon-button`, `.lesson-marker`, плиток меню и аватаров; нажатие — `translateY` на глубину губы, губа схлопывается; reduced motion и клавиатура — без перемещения. Медальоны героев, статичное конфетти на итогах, лучи у награды, сцены-миры с небом и холмами по типу задания, белая карточка под словом, «пузырь» ошибки, плитки-гаражи, корзинка, доска-ступени.
- `Icon.tsx`: системные глифы залиты на сетке 24×24; персонажи и предметы — многоцветные на сетке 64×64, с общим «наивным» лицом. Новые: `bunny`, `chick`, `frog`, `sound`, `sparkle`.
- `App.tsx`: классы состояний маркеров карты, цветные кружки в меню настроек, сообщение об ошибке в отдельном элементе.
- Шрифт: Pofo VF, фактический диапазон оси `wght` 300–700; заголовки и кнопки — 700.
- Тесты: проверка viewBox читает размер сетки иконки; в фикстуру добавлены новые иконки. Сборка, 9 unit, 18 браузерных проверок проходят.
- Сравнение: `evidence/refresh/before-*` и `evidence/refresh/after-*`.

Не проверено: физический сенсорный экран и ощущение «утапливания» кнопки на реальном устройстве.

## Итерация 2 — правки пользователя и сверка с функциональными доработками

- Убран точечный паттерн с фона страницы и устройства: остались ровные тёплые цвета.
- Скрыты плашки «Знакомство · N / 3» в онбординге и «Урок 1 · 6 заданий» на вводной.
- Кольцо текущего урока на карте принадлежит `.map-stop`, а не кнопке. Это окружность вокруг лица маркера вместе с кромкой, с заливкой фоном (дорожка уходит под неё). При нажатии кольцо не сдвигается. Размеры заданы переменными `--marker`, `--marker-lip`, `--ring-gap` для всех раскладок.
- Итог задания и итог тренировки — без конфетти.
- Итог урока — последовательность на токенах из `tokens.css`: звезда «выпрыгивает» (`--motion-reward-pop`), через `--motion-reward-confetti-delay` из двух нижних углов вылетают конфетти (`Confetti` в `motion.tsx`), затем появляются текст (`--motion-reward-text-delay`) и кнопки (`--motion-reward-actions-delay`). «Следующий урок» — основная кнопка и стоит первой. Reduced motion и клавиатурный режим: без анимаций и без конфетти.
- Сверка по `2026-11-03-learning-controls-visual-handoff.md`:
  - панель задания: «Проиграть заново» — круглая кнопка с иконкой `play` (голубая), подсказка — иконка `help` (лавандовая), отмена — `undo` (оранжевая); подписи для экранного чтения прежние;
  - озвучка: иконка мегафона; во время воспроизведения кнопка в нажатом состоянии с иконкой «стоп»; сообщение об ошибке — «пузырь»;
  - диалоги: бумажная карточка с кромкой, мягкое появление, крестик — иконка `close`; второе пояснение в подсказке выделено голубой плашкой; образец слова — белая карточка как в задании;
  - предложение профиля: аватар-иллюстрация в медальоне;
  - меню пройденного урока: зелёная контекстная карточка у маркера «Урок 1» со стрелкой; при нехватке места снизу — сверху; если нет места нигде (667×320) — прижимается к низу экрана без стрелки. Позиция пересчитывается при прокрутке и изменении размера; Escape, закрытие вне карточки и возврат фокуса сохранены нативным диалогом;

## Итерация 3 — поведение мобильного приложения и полноэкранные задания

- Рамка телефона — жёсткая граница: `.device{overflow:clip}`, `.screen-content{overflow:hidden;min-width:0}`, перенос длинных слов. Затемнение под диалогами рисует сам телефон (`.device[data-overlay]::after`), нативный `::backdrop` прозрачный. Все диалоги позиционируются внутри рамки: по центру телефона или у маркера урока с прижатием к краям. Новый браузерный тест `nothing leaves the phone frame` проверяет это на 667×320, 844×390 и 1200×800.
- Ховеры удалены. Кольцо фокуса показывается только после ввода с клавиатуры.
- Диалоги — белые карточки; вторичные кнопки получили кольцо цвета кромки и бумажный фон внутри диалогов, чтобы не сливаться с поверхностью. Карточка действий урока тоже белая, со стрелкой.
- Вводная: еле заметный фон (тёплое свечение сверху, бледные холмы снизу), текст по центру, кнопка «Начать урок» (тесты обновлены под новую подпись).
- Задания: игровой мир заполняет телефон от края до края, панель, прогресс, подсказка и карточка слова — поверх. Название задания и плашка «Задание N / 6» убраны; прогресс по словам — по центру верхней панели; подсказка — крупно (24 px) по центру над игровой зоной. Во время ошибки «пузырь» занимает место подсказки.
- Дуги слогов толще (11), без стрелок и стартовых точек; дуга текущего слога подкрашена.
- «Проиграть заново» во время показа подсвечивается голубым и показывает анимированные полоски. Слог под заполняемой дугой во время показа мягко пружинит (`syllable-bounce`, длительность `--motion-reading-unit`). Reduced motion и клавиатура — без анимации.
- Проверено: сборка, 16 unit, 24 браузерных сценария.
